IMPORTANTE:
1. Suba TODOS los archivos de esta carpeta a un sitio HTTPS que permita archivos estáticos
   (por ejemplo, GitHub Pages).
2. Abra la dirección HTTPS de esa página en Chrome en el Honor 200.
3. Chrome debería mostrar "Instalar aplicación" o permitir "Añadir a pantalla de inicio".
4. La aplicación instalada abrirá el CRM actual dentro de la pantalla de la app.
